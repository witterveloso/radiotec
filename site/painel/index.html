Relógios

Um relógio é o modelo de uma hora. Ele recomeça no início de cada hora; a hora certa só toca nos primeiros 5 minutos.

      Enviar áudios

      Os áudios ficam no GitHub, na pasta acervo. Cada botão abre a pasta certa: arraste os arquivos e clique em Commit changes. Em poucos minutos a rádio é atualizada sozinha.

      Enviar arquivos do programa

      Programas: os arquivos tocam em ordem alfabética, então numere os blocos (01-bloco.mp3, 02-bloco.mp3). Hora certa: nomeie com a hora (14h.mp3).

      Programação publicada

        Relatório de execução (ECAD)

        Gera a planilha com data, hora, título, intérprete, compositor, ISRC e duração de cada música da programação no período. Preencha compositor e ISRC nas tags dos MP3 para o relatório sair completo.

        Publicar a nova programação

        1. Clique em Copiar e abrir no GitHub.
        2. No GitHub, apague todo o texto do arquivo (Ctrl+A) e cole (Ctrl+V).
        3. Clique em Commit changes.
        4. Em 3 a 5 minutos a rádio passa a tocar a nova grade.
